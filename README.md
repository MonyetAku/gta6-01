Solmarina — an original open-world crime game in the browser. Drive and steal cars, outrun the Solmarina PD through a 1–5 star wanted system, and finish five story jobs across a sun-soaked coastal city, with traffic, pedestrians, combat, a live minimap and synthesized sound. Built with three.js, runs fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
